# Repo Watch 界面改版

本轮仅调整 Web 展示、导航与本地筛选，不改变 API、SSO、数据库、扫描计划、告警策略或通知配置。

## 主要变化

- 桌面使用侧边导航，手机使用三列导航；依赖动态、仓库监控和关注设置有明确的当前状态。
- 扫描概览使用数字卡片，分别展示仓库总数、执行/排队、失败、未扫描与逾期，避免把可能重叠的状态相加。
- 仓库列表提前到活动摘要之前，增加名称/描述搜索、扫描状态与通知状态筛选，保留 API 返回的优先顺序。
- 仓库卡片区分失败、排队、扫描中、正常与尚未扫描，展示依赖数、最近/下次扫描和错误信息。
- 静音、优先级、扫描和删除仍调用原有操作；本地搜索/筛选不会修改监控配置。
- 依赖卡片改为窄屏可换行布局，更新类型显示中文标签，空筛选可一键清空。
- 修复未选择仓库时进入关注设置自动跳回列表的问题，设置页允许先选择仓库。
- 增加筛选输入和操作按钮的可访问名称、加载状态、空状态及减少动态效果支持。

## 验证

在 `web/` 中运行：

```bash
npm test
npm run type-check
npm run lint
npm run build
```

新增组件测试使用 `example/*` 隔离测试数据，覆盖组合筛选、无匹配与空列表、原有操作参数、
忙碌状态、搜索焦点、扫描统计、导航往返、设置空状态和添加/取消入口，不连接真实仓库。

云端浏览器只能访问未登录的公开 SSO 入口，且不能访问本地开发地址。
因此本轮没有把隔离测试结果称为真实浏览器视觉验收，也没有制作模拟生产截图。
登录后的桌面/手机实际视觉复查仍需可用的授权测试会话或支持的开发浏览器环境。
